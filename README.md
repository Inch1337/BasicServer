# BasicServer

**BasicServer** — это учебный проект, демонстрирующий создание веб-сервера на языке Go. Проект построен с использованием чистой архитектуры и следует стандартам компоновки Go-проектов (Standard Go Project Layout).

Основная цель проекта — практика работы со стандартной библиотекой `net/http`, взаимодействие с базой данных через `database/sql` и организация кода (clean architecture).

## 🛠 Стек технологий  


*   **Язык**: Go (Golang)

*   **Сервер**: `net/http`

*   **База данных**: PostgreSQL

*   **Конфигурация**: Переменные окружения (.env)

*   **Миграции**: SQL-скрипты

  
## 📂 Структура проекта

```text
BasicServer/

├── cmd/            # Точки входа в приложение (main.go)

├── internal/       # Внутренняя логика (хендлеры, сервисы, репозитории)

├── migrations/     # Файлы SQL для создания таблиц и миграций

├── pkg/            # Общие пакеты и модели данных

│   └── models/     # Структуры данных

├── .envExample     # Пример файла конфигурации

├── go.mod          # Управление зависимостями

└── README.md       # Документация
```

## 🚀 Начало работы

### Предварительные требования

- Go 1.20+[1]
- База данных PostgreSQL

## Установка

### Клонируйте репозиторий:

```Bash
git clone https://github.com/Inch1337/BasicServer.git
cd BasicServer
```

### Установите зависимости:

```Bash
go mod download
```

### Настройка конфигурации:
Создайте файл `.env` на основе примера:

```Bash
cp .envExample .env
```
Откройте файл `.env` и укажите параметры подключения к вашей базе данных и порт сервера.


### Запуск

Запустите сервер

```Bash
go run cmd/main.go
```
Сервер запустится на порту, указанном в .env (по умолчанию, например, :8080).
